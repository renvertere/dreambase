# 🧭 **Template: Vault Dashboard**

**Purpose:**  
To serve as the **central navigation hub** for the entire vault — a live index that dynamically displays every key note type (Atoms, How-Tos, READMEs, Logs, etc.) through Dataview tables.

**Why it was made:**  
The Dashboard ensures you never lose context inside a growing knowledge base.  
It gives you a **single glance overview** of all active learning materials — auto-sorted and always current thanks to Dataview queries.  
It’s the home screen of your knowledge system.

**When to use:**  
Use the Dashboard as the **starting point of any session**.  
It’s designed for quick access, review, or curation — whether you’re adding new material, updating templates, or checking your progress.

**Outcome:**  
A self-updating navigation interface that provides:

- 📄 **Reference Notes** — overviews and course summaries
- 📚 **Atoms** — core technical concepts
- 🛠️ **How-To Guides** — actionable procedures
- 📅 **Daily Logs** — activity and progress tracking
